# Toolbox — releases

Windows companion app for World of Tanks: mod manager, network and driver checks.

**Download** from [Releases](../../releases):
- `Toolbox-win-Setup.exe` — stable builds.
- `Toolbox-test-Setup.exe` — test builds (pre-releases, may be unstable).

Installs per-user (no admin rights) and updates itself automatically; the stable/test
choice is in the app's Settings. This repository holds only release binaries and the
public mod catalog; it contains no source code.
