# Toolbox — releases

Windows companion app for World of Tanks: mod manager, network and driver checks.

**Download:** grab `Toolbox-win-Setup.exe` from the [latest release](../../releases/latest).
Installs per-user (no admin rights) and updates itself automatically.

This repository holds only release binaries and the public mod catalog; it contains no source code.
